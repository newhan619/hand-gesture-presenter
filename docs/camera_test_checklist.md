## 설치와 인식

- [ ] `setup.ps1` 설치와 `pip check`가 통과한다.
- [ ] `run.ps1 -Mode check`에서 모델 추론을 확인한다.
- [ ] `run.ps1 -Mode demo`가 PASS를 출력한다.
- [ ] preview 모드에서 카메라가 열리고 창 닫기·Q·Ctrl+C로 종료된다.
- [ ] 잘못된 카메라 번호 또는 다른 앱의 카메라 점유 시 안내 오류가 나온다.
- [ ] 손 한 개에 관절 21개와 연결선이 표시된다.
- [ ] 오른손과 왼손을 각각 단독으로 보여주었을 때 좌우 손 표시가 맞는다.
- [ ] 0~5개 손가락을 각 5회씩 시험하고 성공/실패 수를 적는다. 조합도 바꿔 본다.
- [ ] 주먹, 편 손, 검지만 편 손을 구분하며 5프레임 미만의 변화는 동작하지 않는다.
- [ ] 손을 빼거나 두 손을 보여주면 제어가 멈춘다.

## 스와이프

먼저 preview 모드의 이벤트만 확인한 뒤 present 모드로 반복한다.

- [ ] 편 손을 유지한 뒤 오른쪽으로 이동하면 다음 장으로 한 번 넘어간다. 10회 기록한다.
- [ ] 왼쪽으로 이동하면 이전 장으로 한 번 넘어간다. 10회 기록한다.
- [ ] 편 손을 계속 유지하며 왕복해도 슬라이드가 추가로 넘어가지 않는다.
- [ ] 주먹으로 복귀하더라도 마지막 입력 후 1초 동안 추가 입력이 없다.
- [ ] 손을 영상 밖으로 뺐다가 다시 편 손으로 나타내도 주먹 복귀 조건을 우회하지 않는다.
- [ ] 천천히 옮기기, 세로 이동, 손 떨림으로 슬라이드가 넘어가지 않는다.

## 포인터와 창 포커스

- [ ] 기본 모니터의 전체 화면 PPT 슬라이드 쇼에서 present 모드로 실행한다.
- [ ] 5초 안에 PPT 창을 선택하면 LIVE INPUT 상태가 된다. 계속 WAIT라면 창 종류와 PPT 버전을 기록한다.
- [ ] 검지만 설정된 프레임 수만큼 유지하면 Ctrl+L로 레이저 포인터가 켜진다. 기본은 5프레임, 시연 설정은 2프레임이다.
- [ ] 검지 이동과 포인터의 상하좌우 방향이 일치한다.
- [ ] 포인터 모드에서 편 손을 움직여도 슬라이드가 넘어가지 않는다.
- [ ] 잠깐 주먹으로 인식돼도 레이저가 유지된다. 주먹을 0.25초 이상 유지하면 Ctrl+A로 화살표 포인터로 돌아온다.
- [ ] 손이 잠깐 안 보이면 포인터 이동이 즉시 멈춘다. 0.4초 안에 같은 손의 검지가 다시 잡히면 이전 좌표와 섞이지 않고 이동을 재개한다.
- [ ] 미검출이 0.4초 이상이면 포인터가 꺼진다. 10초 동안 슬라이드와 포인터 이동 입력이 없으며, 손을 다시 보여 주면 설정된 프레임 수를 채운 뒤 포인터가 켜진다.
- [ ] 스무딩 1.0과 0.3으로 각 3초 고정한 결과의 흔들림과 지연을 비교한다.
- [ ] 다른 앱을 선택하면 해당 앱에 제스처 입력이 전달되지 않는다.
- [ ] PPT 창으로 돌아오면 손 모양을 새로 확인한다.
- [ ] 직접 마우스를 화면 모서리로 옮겼을 때 비상 중단을 확인한다.

## 데스크톱 모드

- [ ] `run.ps1 -Mode desktop-demo`에서 `click`, `drag_start`, `drag_move`, `drag_end`, `pause`와 실제 입력 0회를 확인한다.
- [ ] `run.ps1 -Mode desktop-preview`에서 `Mode`, `Shape`, `Action`을 보며 각 동작을 시험한다.
- [ ] `run.ps1 -Mode desktop`으로 빈 폴더나 연습용 문서에서 검지 커서 이동과 짧은 핀치 클릭을 확인한다.
- [ ] 엄지와 검지를 붙인 채 파일이나 창을 끌고, 손가락을 떼면 놓는지 확인한다. 드래그 중 손을 빼거나 주먹을 쥐었을 때도 버튼을 놓는지 본다.
- [ ] 검지와 중지만 펴서 위아래로 움직이면 스크롤한다. 편 손으로 좌우 스와이프하면 창이 각각 한 번 바뀐다.
- [ ] 주먹을 쥐고 손을 움직이면 아무 입력도 없고, 주먹을 풀면 조작할 수 있다.

macOS에서는 `bash run.sh desktop-demo`, `bash run.sh desktop-preview`, `bash run.sh desktop`을 차례로 실행한다. 실제 입력 전에 터미널의 손쉬운 사용 권한을 허용하고, 카메라를 열 때 권한을 요청하면 허용한다.

- [ ] macOS에서 Finder나 연습용 문서로 클릭, 드래그 해제, 스크롤, 주먹 일시정지를 시험한다.
- [ ] 서로 다른 앱을 3개 이상 열고 좌우 스와이프로 `⌘+Tab` / `⌘+Shift+Tab` 전환을 확인한다.

## 통합 시연

- [ ] 실제 발표 슬라이드로 5분 연속 동작한다.
- [ ] 밝기와 거리 조건을 바꾸어 성공률과 FPS를 적는다.
- [ ] 종료 후 카메라를 다른 앱에서 다시 열 수 있다.
- [ ] 8~10분 리허설에서 구현 원리, 제안서 대비 차이, 미검증·미구현 항목을 설명한다.
